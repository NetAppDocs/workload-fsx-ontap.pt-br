= Utilize backups para proteger os dados no NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Proteja os dados do seu volume contra exclusão acidental, corrupção e outros eventos de perda de dados criando e restaurando backups no NetApp Workload Factory. Você pode configurar um agendamento de backup, criar um backup sob demanda de um volume fora dos seus backups regulares e restaurar um volume a partir de um backup existente para qualquer sistema de arquivos FSx for ONTAP na sua conta AWS.



[[create-an-on-demand-backup-of-a-volume]]
== Crie um backup sob demanda de um volume

Crie um backup manual de um volume fora dos backups agendados regularmente no NetApp Workload Factory.

.Sobre esta tarefa
Os backups de volume são feitos por volume, portanto, cada backup contém apenas os dados em um volume específico.

Os backups de volume são incrementais, o que significa que apenas os dados do volume que foram alterados após o backup mais recente são salvos. Isso minimiza o tempo necessário para criar o backup e o armazenamento necessário para o backup, o que reduz os custos de armazenamento ao não duplicar dados.

.Antes de começar
Para fazer backups de seus volumes, tanto o volume quanto o sistema de arquivos precisam ter capacidade de armazenamento SSD disponível suficiente para armazenar o snapshot de backup. Ao tirar um snapshot de backup, a capacidade de storage adicional consumida pelo snapshot não pode fazer com que o volume exceda 98% da utilização do storage SSD. Se isso acontecer, o backup falhará.

.Passos
. Inicie sessão utilizando uma das link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiências de console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até cargas de trabalho como armazenamento, EDA, IA, bancos de dados, VMware e administração."] Em seguida, selecione *Armazenamento*.
. No menu Storage, selecione *Volumes explorer*.
. Selecione o menu de ações para o volume que você deseja fazer backup.
. Selecione *Ações de proteção de dados*, *Backups de volume* e, em seguida, *Backup manual*.
. Na caixa de diálogo cópia de segurança manual, introduza um nome para a cópia de segurança.
. Selecione *Backup*.




[[restore-a-volume-from-a-backup-in-netapp-workload-factory]]
== Restaurar um volume de um backup no NetApp Workload Factory

No NetApp Workload Factory, você pode restaurar um volume de um backup para qualquer sistema de arquivos FSx for ONTAP na sua conta da AWS.

O Workload Factory determina se você tem capacidade suficiente para a restauração e pode adicionar automaticamente capacidade de storage SSD caso você não tenha.

.Passos
. Inicie sessão utilizando uma das link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiências de console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até cargas de trabalho como armazenamento, EDA, IA, bancos de dados, VMware e administração."] Em seguida, selecione *Armazenamento*.
. No menu Storage, selecione *Volumes explorer*.
. Selecione o menu de ações para o volume que você deseja restaurar a partir de um backup.
. Selecione *Data protection actions*, *Volume backups* e, em seguida, *Restore from a backup*.
. Na caixa de diálogo Restaurar a partir de uma cópia de segurança, forneça o seguinte:
+
.. * Sistema de arquivos de destino*: Selecione o sistema de arquivos de destino no menu suspenso.
.. *Target storage VM*: Selecione a VM de armazenamento de destino no menu suspenso.
.. *Nome da cópia de segurança*: Selecione o nome da cópia de segurança no menu pendente.
.. *Nome do volume restaurado*: Insira o nome do volume restaurado.


. Verifique a capacidade do sistema de arquivos para a operação de restauração.
+
Quando a capacidade do sistema de arquivos é limitada, pode ocorrer o seguinte:

+
** A restauração pode fazer com que a capacidade utilizada ultrapasse o limite que você especificou. Você pode concluir a operação de restauração. Considere link:adjust-file-system-capacity.html["Adicionar manualmente a capacidade da camada de storage SSD"]ou selecionar para o NetApp Workload Factory adicionar automaticamente capacidade de storage em SSD.
** A restauração requer capacidade SSD adicional.  Você deve selecionar o Workload Factory para adicionar automaticamente a capacidade de armazenamento SSD para continuar.


. Selecione *Restaurar*.
