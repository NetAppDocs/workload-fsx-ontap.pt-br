= Monitore custos e obtenha relatórios de recursos no NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Workload Factory oferece uma visão consolidada dos custos e do uso do seu sistema de arquivos FSx for ONTAP, ajudando você a gerenciar orçamentos e otimizar recursos com eficiência. Você também pode gerar relatórios de custos dos recursos do seu sistema de arquivos FSx for ONTAP para compartilhar com as partes interessadas.



[[about-this-task]]
== Sobre esta tarefa

O Workload Factory monitora os custos e o uso do sistema de arquivos FSx for ONTAP obtendo dados de custo do AWS Cost Explorer. Os seguintes detalhes de custo são monitorados: tipo de uso, SKU de uso, tipo de implantação, uso e custo total.

Para recursos exclusivos, o Workload Factory calcula os custos combinando o uso real do nível de desempenho, uma parcela proporcional dos custos do nível de desempenho alocada ao espaço provisionado, mas não utilizado, as alocações de desempenho distribuídas por capacidade e o uso do pool de capacidade. O Workload Factory multiplica cada componente pelo seu preço por unidade para essa dimensão e soma os resultados para determinar o custo total de cada recurso.

No painel de custos, você pode filtrar os dados de custo e uso por contas da AWS, credenciais, uma ou mais regiões e intervalos de tempo para entender o consumo do seu sistema de arquivos FSx for ONTAP. O Workload Factory sempre exibe os dados em uma taxa mensal. Você também pode filtrar por um ou mais sistemas de arquivos e um ou mais volumes em um sistema de arquivos. As chaves de tag de alocação de custos da AWS e os valores de chave de tag adicionam uma camada adicional de filtragem para identificar custos específicos. Uma _tag_ consiste em uma chave e um valor. Para filtrar por chaves de tag e valores de chave de tag, atribua tags aos seus sistemas de arquivos FSx for ONTAP. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["Saiba mais sobre as tags de alocação de custos da AWS."^]

O Workload Factory obtém dados de custo e uso para os recursos do seu sistema de arquivos FSx for ONTAP do AWS Cost Explorer usando as seguintes permissões: `ce:GetCostAndUsage` e  `ce:GetTags`. Calculamos o custo total usando a API de custos da AWS e nossas próprias estimativas.

Além dos dados de custos no painel de Custos, o resumo executivo de custos mostra os custos do seu sistema de arquivos FSx for ONTAP e os padrões de gastos da sua organização. Você também pode gerar relatórios de custos para os recursos do seu sistema de arquivos FSx for ONTAP. O relatório é um arquivo CSV para download que você pode compartilhar com as partes interessadas.



[[track-costs]]
== Acompanhe os custos

Os custos exibidos no painel de custos do console do Workload Factory são baseados nos dados do AWS Cost Explorer, que são atualizados a cada 24 horas.

.Antes de começar
Verifique se você atende aos seguintes requisitos:

* Você precisa link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Conceder credenciais com a política de permissão _visualizar, planejar e analisar_"^] no Workload Factory para rastrear os custos do FSx para ONTAP.
* Para filtrar por tags de alocação da AWS, verifique se os seus sistemas de arquivos Amazon FSx for NetApp ONTAP têm tags atribuídas.


.Passos
. Inicie sessão utilizando uma das link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiências de console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até cargas de trabalho como armazenamento, EDA, IA, bancos de dados, VMware e administração."] Em seguida, selecione *Armazenamento*.
. No menu Armazenamento, selecione *Custo*.
. No painel de custos, filtre os dados de custo e capacidade dos seus recursos FSx for ONTAP fornecendo o seguinte:
+
.. *Contas da AWS*: Selecione as contas para as quais deseja visualizar os dados de custo.
.. *Credenciais*: Selecione as credenciais com permissões de _visualização, planejamento e análise_.
.. *Regiões*: Selecione as regiões da AWS para as quais você deseja visualizar os dados de custo.
.. *Intervalo de dados de custo*: Selecione o intervalo de tempo para visualizar os dados de custo.
.. *Chave de tag de alocação*: (Opcional) Selecione uma chave de tag de alocação e seu valor para gerar um relatório de custos detalhado para todos os sistemas de arquivos FSx for ONTAP associados à tag AWS.
.. *Valores da tag de alocação*: (Opcional) Selecione o valor da chave da tag de alocação que está associado à chave da tag de alocação para gerar um relatório de custos detalhado para todos os sistemas de arquivos FSx for ONTAP associados à tag da AWS.


. Veja os *Detalhes de Custo* dos seus recursos FSx para ONTAP .




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== Gere relatórios de custos para seus recursos FSx for ONTAP

Gere relatórios de custos para recursos específicos do sistema de arquivos FSx for ONTAP para compartilhar com as partes interessadas.

.Passos
. No painel de custos, selecione *Gerar relatório*.
. Na tela de Relatório, forneça as seguintes informações:
+
.. *Sistema de arquivos*: Selecione um ou mais sistemas de arquivos FSx for ONTAP para incluir no relatório.
.. *Volume*: (Opcional) selecione um ou mais volumes para incluir no relatório.




.Resultado
Um relatório em CSV é gerado e pode ser baixado.
